# Core Deep Learning Architectures & Optimization Pipelines

This repository documents an intensive, hands-on journey into advanced Deep Learning and Neural Network mechanics from scratch. The implementations transition systematically from foundational mathematics to production-grade network architectures, fully executed using a cloud-connected Google Colab environment with automated model persistence.

*   **Computing Environment:** Google Colab (T4 GPU Accelerated) integrated with Google Drive for secure model lifecycle management.

## Technical Content & Directory Structure

### 📁 01_Perceptron_and_MLP_Basics
This module focuses on the transition from single linear decision limits to deep hidden network layers capable of handling complex coordinate intersections.
*   **Custom Perceptron Engine:** Pure NumPy implementation of a single-layer vector neuron incorporating manual weight matrices initialization, threshold step functions, and iterative coordinate update feedback parameters.
*   **AND Gate Verification:** Computational validation showing structural weights convergence and linear optimization space contours.
*   **Multi-Layer Perceptron (MLP):** Hidden layer deep learning setup built using Keras Sequential API to map complex non-linear classification limits (XOR Gate logic). Includes deep spatial mapping validation pipelines.

### 📁 02_Deep_Calculus_and_Backpropagation
A framework-free implementation executing the complete mathematical operations behind continuous neural network optimization.
*   **Matrix Propagation Engine:** Manual layout execution of forward dot-product transformations and bias additions across independent dense hidden structures.
*   **Calculus Chain-Rule Backpropagation:** Pure array-level calculation of local derivatives, mapping vector gradients for weights and bias dimensions without relying on automated gradient libraries.
*   **Loss Optimization Pipeline:** Implementation of cross-entropy cost adjustments over extended epochs, visualizing real-time mathematical convergence curves.

### 📁 03_Activation_Functions_and_Loss
An empirical exploration analyzing structural behavior, bounding criteria, and mathematical cost functions inside layered deep setups.
*   **Advanced Activation Arrays:** Code matrices mapping the mathematical limits of Sigmoid, Hyperbolic Tangent (Tanh), Rectified Linear Unit (ReLU), and Leaky ReLU. Includes comprehensive multi-plot coordinate layouts.
*   **Loss Mechanics Evaluation:** Comparative implementation profiling the operational variance between binary log-loss structures and quadratic regression error fields.
